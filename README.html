Publicação no GitHub Pages

O projeto usa HTML, CSS e JavaScript puro. Não precisa de servidor, banco de dados nem etapa de build.

Versão 8100% estáticoGitHub Pages

Como publicar

  1. Crie um repositório no GitHub.
  2. Envie todos os arquivos e pastas deste pacote para a raiz do repositório.
  3. Abra Settings → Pages.
  4. Em Build and deployment, escolha a branch principal e a pasta raiz /.
  5. Salve e acesse o endereço informado pelo GitHub Pages.

Arquivos principais

ArquivoFunção
index.htmlPágina principal e acesso à trilha.
modulos/Nove momentos formativos.
assets/css/style.cssIdentidade visual e responsividade.
assets/js/app.jsProgresso, notas, acessibilidade e recursos do curso.
assets/js/assessment.jsBanco e lógica da avaliação final.
instrutor.htmlÁrea reservada ao instrutor com gabarito e orientações.

Importante sobre os dados

Progresso, anotações e respostas são armazenados em localStorage, no navegador do próprio aluno. Use a página Meus dados para exportar um backup.
