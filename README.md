# IA para Empreendedores — versão 9

Site estático autoinstrucional baseado no Plano de Curso **Iniciação Profissional em Inteligência Artificial para Empreendedores**.

## Carga horária
A trilha principal foi recalibrada para fechar exatamente **8 horas (480 minutos)**. Recursos complementares ficam fora do tempo-base.

## Destaques da v9
- acabamento visual institucional e consistente;
- nova **Ficha do Curso**;
- novo **Plano de Estudos** com distribuição exata de 480 minutos;
- matriz de alinhamento entre módulos e ementa;
- rodapés e metadados padronizados;
- mantém progresso local, avaliação dinâmica, certificado simbólico, modo instrutor, busca, backup e acessibilidade.

## Publicação
1. Envie o conteúdo desta pasta para um repositório GitHub.
2. Em **Settings > Pages**, publique a branch principal a partir da raiz (`/`).
3. Abra `index.html` pelo endereço do GitHub Pages.

> O certificado gerado pelo site é simbólico e não substitui certificação institucional, pois o site não controla frequência oficial.
